# 《留白》参考图编目

2026-11-15 · 素材包 `留白_materials_v0.2.zip` 在 `materials/incoming/2026-11-13/`，之后追加的三张图在 `materials/incoming/2026-11-14/`

（2026-11-19：当前成片 v8 是没有人物的第一人称版，跟着一个“留白光点”走；下面“旅人”一节说的是 v5 的人物，代码保留。v8 新加的场景细节（石板路、圆石、草、藤、陶罐、灯笼、芦苇、睡莲、树根、蘑菇、栏杆、旗幡、石堆）没有对应的参考图，是按各幕的画稿风格补的。）

**所有图都只作参考**：场景里的每样东西都是照着参考图用 Three.js 建的模型，由水彩着色器画出来，成片里不放任何图。旅人从 v0.7 起也不再用人设原画（v0.6 的图钉木偶太僵、太糙）；v0.8 起旅人只有披风、短披肩和头发，全部是物理模拟，没有躯干和四肢，也不画脸。下面逐项列出照的是哪一张、建成了什么、和原画差在哪里。场景模型在 `src/scenes.js`，旅人在 `src/traveller.js`。

### 第 2 幕　灰

| 参考图 | 建成了什么 | 差别 |
|---|---|---|
| `R3f_3` 石柱列 | 路后方的一长排多立克柱：方座、柱础线脚、带二十道凹槽的柱身（由四节鼓石垒成，略有错位）、柱头、分块的横梁。其中几根折断，有一根像图里那样上半截还挂在横梁下。整排立在两级台阶上。冷蓝灰。 | 原画的柱子有手绘的斑驳，这里是着色器生成的水痕。 |
| `R4f_3` 三根石柱 | 路前方的近排：一根光面的爱奥尼柱（带卷涡）、一根有凹槽的、一根有凹槽的断柱。暖灰。断柱立在第一个镜头的左缘。 | 第二根在原画里是科林斯柱头，这里简化成爱奥尼。 |
| `R2w2_3` 断拱 | 远处的巨拱：左柱完整（方座、三节鼓石、柱头），十一块拱石从左侧起拱越过拱顶，拱心石略突出；右柱只剩三节，最上一节歪着、断口参差；地上有掉下来的拱石。钢蓝色。 | |
| `R1w_1` 高架渠 | 最远处的两层高架渠：下层高拱，上层每跨两个小拱窗，束腰线脚，凸出的墩柱，砌缝；左端像图里那样成阶梯状塌掉，再往左隔一段还有一截残墙。暖米色。 | 砌缝是着色器画的，不是一块块石头。 |
| `R5f_3`、`R5f_4` 碎石 | 散落的鼓石（横躺，露出带凹槽的断面）、方石、碎岩，分布在近处、柱列脚下和断拱下面。 | |
